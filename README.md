# IvanNovR's Homebrew Tap

My Homebrew packages for macOS.

## Installation

```sh
brew tap IvanNovR/ivannovr
```

## Available packages

- [SF Mono Nerd Font](https://github.com/IvanNovR/sf-mono-nerd-font) — Apple's SF Mono with Nerd Fonts icons.

```sh
brew install --cask IvanNovR/ivannovr/font-sf-mono-nerd-font
``
